## Motivation

Why this project exists.

- Acelerar la extracción de scripts de despliegue/versión de objetos SQL Server.
- Evitar el trabajo manual de generar `DROP` + `CREATE` objeto por objeto en SSMS.
- Preservar metadatos (esquema, tipo, propiedades extendidas `MS_Description`) al
  regenerar scripts.

## Problem

Concrete problems the project solves.

- Obtener el `CREATE` real y actualizado de múltiples objetos de una base es tedioso
  y propenso a omitir el `DROP IF EXISTS` o las propiedades extendidas.
- No hay una forma rápida de procesar en lote una lista pegada de objetos.

## Solution

How the project addresses the problems above.

- El usuario pega una lista de objetos (uno por línea), elige la base y pulsa
  **Ejecutar**; la app consulta `OBJECT_DEFINITION` y arma el bloque `DROP`/`CREATE`.
- Resultado copiable o descargable como `.sql`, con resaltado T-SQL.
- Comparación de SP/funciones pegados o importados contra la misma conexión/base,
  con detección local de objetos, parámetros y filas alineadas.

## Constraints

Non-negotiable boundaries.

- La app **no posee ni administra un esquema de base de datos propio**: solo lee
  metadatos de SQL Server y genera T-SQL de salida.
- Única persistencia local: `environments.json` en el directorio de config de la app.
- Toda E/S a SQL Server ocurre en el backend Rust; el frontend nunca abre conexiones.
- Windows-only en la práctica (WebView2 + autenticación integrada Windows).

## Scope

What is included in the project scope.

- Conexión a SQL Server (auth SQL o Windows integrada), instancias con nombre y
  `HOST,puerto`.
- Generación de scripts `DROP IF EXISTS` + `CREATE` para procedimientos, funciones,
  vistas y triggers con definición disponible. No reconstruye tablas mediante
  `OBJECT_DEFINITION`.
- Gestión de múltiples entornos de conexión con base por defecto.
- Copiar todo / descargar `.sql`.
- Comparación de contenido y parámetros de SP/funciones; importación de archivos
  y navegación sincronizada por diferencias.
- Fuera de alcance: la carpeta `docs/` (omitida en esta documentación).

## Goals

Measurable targets the project aims to hit.

- Generar scripts correctos y completos (con propiedades extendidas) por lote.
- Distribución como instalador Windows (`.exe` NSIS / `.msi`) sin datos precargados.

## Dependencies

External systems, libraries, or services the project relies on.

- SQL Server accesible por el usuario (motor externo, no incluido).
- Tauri v2, `tiberius` (driver SQL Server), `tokio`, `serde`, `rfd`.
- WebView2 (runtime del sistema, Windows 11).
